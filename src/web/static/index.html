    Delivery Route Steps

    Graph (Adjacency List)

    Stores city intersections, restaurants, and customer houses inside our custom HashMap. Since city road networks are sparse, an adjacency list uses O(V + E) memory instead of an O(V²) matrix.

    Priority Queue (Binary Min-Heap)

    An array-based binary heap with FIFO tie-breaking. It selects the closest unvisited node in Dijkstra's algorithm and ranks candidate stops in O(log N) time per operation.

    Hash Map (Separate Chaining)

    Automatically resizes when the load factor exceeds 0.75. It provides O(1) average lookup time for graph nodes, distance tables, and active orders.

    Live Performance Benchmark

    Compares MinHeap O(log N) with Linear Scan O(N), and MinHeap Dijkstra O((V+E) log V) with Naive Dijkstra O(V²) directly on the server.
